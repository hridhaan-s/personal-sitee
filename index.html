Building this portfolio without frameworks

No React, no bundler, no node_modules. Just the three languages the browser already speaks.

I wanted a place where I could put everything I achieve and learn, so I made it without using React or any framework. Every tutorial pushes you toward a stack before you have a problem that needs one, and a personal site is not that problem.

The stack

HTML, CSS and JavaScript. That is the whole list. There is no build step, which means the file I edit is the file the browser runs, and debugging is just reading.

Domain and hosting

Vercel for hosting and Odoo for the domain. Vercel rewrites every route back to the root, which is what lets the small client-side router handle /achievements and /blog without separate HTML files.

What I would tell past me

Keep the CSS in ordered files from day one. A single stylesheet that only ever grows is fine until the day you need to find something in it, and then it is not fine at all.
